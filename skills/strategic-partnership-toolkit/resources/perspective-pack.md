# Perspective Pack

## Purpose

Expose alternative readings, hidden biases, and uncomfortable questions about a partnership opportunity. This tool does NOT make recommendations. It opens perspectives.

## When to use

- When the user asks "what am I not seeing?"
- When the user wants "blind spots" or "biases"
- When the opportunity involves multiple entities with different incentives
- Before any decision-oriented analysis (as Tool 0.5, pre-analysis)

**Do NOT use when** the user explicitly asks "should we do this?" — that calls for the full pipeline and a decision memo.

## Core principle

**Opening, not closing.** This tool generates questions and alternative readings. It does not answer them. It does not score them. It does not render a verdict.

## Method

### Step 1: Source Lock Statement

Run the source lock gate first. Quote verbatim. Define IS/IS NOT frame.

### Step 2: Actor Separation

Run the actor separation checkpoint. Table with nature, incentives, constraints, gains, risks.

### Step 3: Alternative Readings (minimum 7)

For each reading, answer three questions:

```
### Reading [Letter]: [Name]
- **What must be TRUE** for this to be the dominant reading
- **Evidence supporting it** (source IDs)
- **Evidence contradicting it** (source IDs)
```

Standard readings to consider (customize per case):
- **A: Philanthropic** — Genuine desire to help
- **B: Academic** — Need for data/publication/case study
- **C: Institutional** — Need metrics for program renewal/justification
- **D: Vendor funnel** — "Free" as acquisition channel
- **E: Clinical gap** — Solves a real unmet need
- **F: Casting wide** — Recipient is one of many, not special
- **G: Research access** — Vulnerable population = unique data opportunity
- Add more as needed for the specific case.

### Step 4: Bias Map

```
| Actor | Possible biases |
|-------|----------------|
| [Actor] | [specific biases with context] |
```

At minimum: the user, the counterpart, the institution(s), the vendor(s).

### Step 5: What Different Actors Would Ask

How would this look from the perspective of:
- A lawyer reviewing the agreement
- A patient advocacy group
- The relevant clinical specialist
- IT/security team
- Ethics committee
- Regulatory authority
- A journalist

One question per actor minimum. Focus on what each actor would notice that others miss.

### Step 6: Uncomfortable Questions (minimum 12)

Questions the opportunity avoids or that haven't been asked. These should make all parties slightly uncomfortable.

### Step 7: Evidence Gaps

```
| Gap ID | Description | Impact | How to resolve |
|--------|-------------|--------|---------------|
```

Mark all gaps as [SOURCE GAP]. Unknowns are not weaknesses — pretending they don't exist is.

## Absolute rules

1. **NO recommendation.** Not implicit, not hinted, not "between the lines."
2. **NO GO/PAUSE/STOP.** Not in any form.
3. **NO PASS/FAIL.** Not in any form.
4. **NO scoring.** No weighted matrices, no numerical verdicts.
5. **NO decision gates.** This is perspective, not decision.
6. **Source everything.** Use source IDs from the evidence ledger.
7. **The user decides.** This tool's job is to make sure the user sees more angles, not fewer.

## Output format

Standard sections 1-7 as described. No verdict section. No recommendation section. The document ends with evidence gaps.
