# Strategic Analysis Audit Checklist

Use this checklist after all six strategic skills have been run and before writing the final deliverable.

## 1. Skill coverage audit

| Required skill | Completed? | Missing output | Fix required |
|---|---|---|---|
| strategic-situation-assessment | Yes/No | | |
| stakeholder-power-map | Yes/No | | |
| pilot-readiness-map | Yes/No | | |
| risk-governance-review | Yes/No | | |
| conference-readiness-map | Yes/No | | |
| decision-memo-writer | Yes/No | | |

If any skill is not completed, do not deliver final output.

## 2. Source discipline audit

- [ ] Was context discovery performed before analysis?
- [ ] Were user-provided profiles/notes added to the source base when available?
- [ ] Are direct facts separated from inference?
- [ ] Are user interpretations labeled as internal interpretation?
- [ ] Are public facts cited or source-linked when possible?
- [ ] Are unknowns explicitly listed?
- [ ] Is any claim stronger than its source?

## 3. Strategic coherence audit

- [ ] Does the recommendation match the opportunity?
- [ ] Is the recommended scope narrower than the long-term ambition?
- [ ] Is there a clear strategic clock?
- [ ] Is there a concrete next artifact?
- [ ] Is there a clear owner?
- [ ] Is the plan politically realistic?

## 4. Stakeholder audit

- [ ] Did Source Lock Gate pass?
- [ ] Did Actor Separation pass?
- [ ] Are formal decision makers identified?
- [ ] Are informal influencers identified?
- [ ] Are operational owners identified?
- [ ] Are ethical/legal/data owners identified?
- [ ] Is there a message sequence?
- [ ] Is there a risk of bypassing someone important?

## 5. Pilot audit

- [ ] Is this really a pilot, or a disguised product launch?
- [ ] Is the pilot question clear?
- [ ] Are inclusion/exclusion criteria narrow?
- [ ] Is patient vulnerability addressed?
- [ ] Is consent addressed?
- [ ] Are metrics realistic?
- [ ] Are claims bounded to feasibility/usability/technical validation if appropriate?

## 6. Risk/governance audit

- [ ] Is voice treated as sensitive identity-linked data?
- [ ] Is clinical status treated as sensitive data?
- [ ] Is data storage/transfer addressed?
- [ ] Is vendor dependency addressed?
- [ ] Are stop conditions defined?
- [ ] Are actions not yet permitted clearly listed?
- [ ] Is evidence separated from authority?

## 7. Conference-readiness audit

- [ ] Is the event confirmed or still ambiguous?
- [ ] Is the audience known?
- [ ] Are required artifacts listed?
- [ ] Are claims classified (safe now / safe after data / hypothesis only / do not say)?
- [ ] Is there a backward timeline?
- [ ] Is there a minimum viable presentation if evidence is early?

## 8. Decision memo audit

- [ ] Does the memo ask for a real decision?
- [ ] Are options compared?
- [ ] Is one option recommended?
- [ ] Are risks visible?
- [ ] Are next 14 days concrete?
- [ ] Is the wording safe for institutional circulation?

## 8.5 Grill audit

- [ ] Were major hypotheses explicitly challenged before final output?
- [ ] Were user corrections incorporated into the final analysis?
- [ ] Are unresolved assumptions still visible as limitations?

## 9. Red flags

If any red flag appears, mark final output as preliminary:

- "We are ready" without evidence.
- "This proves" when only feasibility exists.
- "Patients will benefit" without patient data.
- "FALP has approved" without explicit approval.
- "The partner will..." without confirmation.
- "Conference presentation confirmed" without event confirmation.
- "Data is safe" without governance review.
- "We can start with patients" without consent path.

## 10. Arithmetic and matrix verification

If any weighted matrix, scoring table, or numerical comparison exists:

- [ ] **Weight sum check:** Weights add up to the stated maximum (e.g., if max is 26, Σ weights = 26)
- [ ] **Weighted score check:** Each weighted score = weight × raw score (verify a sample of cells)
- [ ] **Total check:** Column/row totals are correct (recompute independently)
- [ ] **Normalization check:** Denominator matches actual maximum (e.g., if weights sum to 26 and max raw = 5, denominator = 130, not 175)
- [ ] **Threshold check:** Thresholds align with normalization (e.g., 3.5/5 is achievable, not impossible)

If ANY arithmetic error is found, the matrix is invalid. Do not deliver. Fix or remove.

## 11. Final clearance

Before final output, write:

```
Audit result:
- Pass
- Pass with limitations
- Fail — preliminary only

Residual limitations:
- limitation 1
- limitation 2
- limitation 3
```
