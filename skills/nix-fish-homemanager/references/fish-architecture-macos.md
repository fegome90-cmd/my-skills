# Fish Shell Architecture on macOS

## 1. Fish Initialization Sequence

When Fish starts, it loads configuration in the following strict order:

```text
1. System configs (/opt/homebrew/share/fish/config.fish or Nix store)
2. ~/.config/fish/conf.d/*.fish (Executed in alphabetical/lexical order)
3. ~/.config/fish/config.fish (Generated by Home Manager)
4. Autoloaded functions (~/.config/fish/functions/*.fish — lazy loaded on first call)
5. Autoloaded completions (~/.config/fish/completions/*.fish)
```

> **Architectural Rule:** Code in `conf.d/` executes **before** `config.fish`.
> This makes `conf.d/` ideal for secret loaders, environment initialization, and early overrides.

---

## 2. Managed vs. Editable Boundary

| Location | Managed By | Strategy | Rule |
| :--- | :--- | :--- | :--- |
| `~/.config/fish/config.fish` | Home Manager (`fish.nix`) | **Read-Only / Generated** | Never edit imperatively; change `fish.nix` and rebuild |
| `~/.config/fish/conf.d/` | Hybrid / User | **Dynamic & Secret Loaders** | Put modular `.fish` scripts (Keychain loaders, aliases, local overrides) |
| `~/.config/fish/functions/` | User & Nix Plugins | **Autoloaded Functions** | One function per file matching `<function_name>.fish` |
| `~/.config/fish/completions/` | Carapace / Nix | **Dynamic Completions** | Carapace handles multi-shell bridges |

---

## 3. Dynamic Function Autoloading

In Fish, functions should not be piled up in a single monolithic file. Place them in `functions/<name>.fish`:

```fish
# File: ~/.config/fish/functions/fish_tab_title.fish
function fish_tab_title --description "Dynamic terminal tab title: worktree · branch"
    set -l git_root (command git rev-parse --show-toplevel 2>/dev/null)
    if test -n "$git_root"
        set -l repo (basename "$git_root")
        set -l branch (command git branch --show-current 2>/dev/null)
        if test -z "$branch"
            set branch (command git rev-parse --short HEAD 2>/dev/null)
        end
        if test -n "$branch"
            echo "$repo · $branch"
        else
            echo "$repo"
        end
    else
        prompt_pwd -d 1 -D 1
    end
end
```

## 4. Mandatory Validation Gates for Fish Code

Every `.fish` script must pass two strict checks before deployment:

```bash
# 1. Format and check indentation
fish_indent -w path/to/script.fish && fish_indent --check path/to/script.fish

# 2. Static syntax check (no execution)
fish -n path/to/script.fish
```
