# Section Splits by Document Type

## §1 — Research Form (CIIC / FALP UIEC) — 20 Chunks

| # | File | Content |
|---|------|---------|
| 01 | metadata.md | Title, investigators, institution, date |
| 02 | resumen.md | Abstract/summary (structured: intro, objective, methods, importance, limitations) |
| 03 | marco-teorico.md | Literature review / theoretical framework |
| 04 | bibliografia.md | References list (all [N] markers) |
| 05 | pregunta-investigacion.md | Research question (PICOT format) |
| 06 | hipotesis.md | Hypotheses (H0, H1, qualitative supuesto) |
| 07 | objetivos.md | General + specific objectives |
| 08 | diseno-estudio.md | Study design (type, paradigm, justification) |
| 09 | poblacion.md | Target population definition |
| 10 | tamano-muestra.md | Sample size calculation (quantitative + qualitative) |
| 11 | muestreo.md | Sampling method and strategy |
| 12 | elegibilidad.md | Inclusion and exclusion criteria |
| 13 | variables.md | Variables table (independent, dependent, control) |
| 14 | recoleccion-datos.md | Data collection instruments and procedures |
| 15 | analisis-estadistico.md | Statistical analysis plan |
| 16 | trabajo-adelantado.md | Preliminary work / pilot data |
| 17 | procedimientos.md | Step-by-step procedures (recruitment → consent → data collection) |
| 18 | cronograma.md | Timeline / Gantt chart |
| 19 | aspectos-eticos.md | Ethics (committee, consent, disclosure, retention, distress) |
| 20 | financiamiento.md | Budget / funding |
