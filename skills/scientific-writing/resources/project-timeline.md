# Project Timeline: From Idea to Submission

> Resource for `scientific-writing` skill. Use when planning a manuscript, tracking progress, or diagnosing a stalled project.

---

## Overview

A scientific manuscript is a multi-phase project. Treat it like one: define milestones, estimate effort, and build in buffer time for revision. The timeline below assumes a single author or small team working on a clinical/observational study. Systematic reviews, lab-based studies, and multi-site trials may take longer.

---

## Phase Map

| Phase | Task | Typical Duration | Depends On | Parallel Tracks |
|-------|------|-----------------|------------|-----------------|
| **0. Self-assessment** | Define question, scope, target journal | 1–2 days | — | Literature scan |
| **1. Literature review** | Systematic search, gap identification | 1–2 weeks | Phase 0 | Gap analysis, citation library setup |
| **2. Data & methods** | Gather data, define analysis plan | 1–4 weeks | Phase 0 | Reporting guideline selection (CONSORT/STROBE/PRISMA) |
| **3. Outline** | Section-by-section outline with key points | 2–3 days | Phases 1–2 | Figure/table sketching |
| **4. First draft** | Convert outline to flowing prose | 1–2 weeks | Phase 3 | Reference compilation |
| **5. Internal review** | Co-authors, mentor feedback | 1–2 weeks | Phase 4 | Identify gaps, verify stats |
| **6. Revision** | Address feedback, polish, audit | 3–5 days | Phase 5 | Grammarly/Hemingway pass |
| **7. Pre-delivery audit** | Run 33-item checklist | 0.5 day | Phase 6 | Ethics verification |
| **8. Submission** | Format per journal guidelines, cover letter | 1 day | Phase 7 | — |
| **9. Revision round 1** | Address reviewer comments | 1–3 weeks | After journal response | Literature update if requested |
| **10. Acceptance → proof** | Copyediting, galley review | 1–2 weeks | After acceptance | — |

**Total estimated timeline:** 8–16 weeks (first submission), +4–8 weeks (to acceptance)

## Phase Details

### Phase 0 — Self-Assessment (1–2 days)

**Goal:** Confirm the paper has a reason to exist.

- [ ] State the research question in one sentence (PICO/PECO/PCCO)
- [ ] Identify the novelty: what does this add to existing literature?
- [ ] Define target audience (specialist journal vs. generalist)
- [ ] Shortlist 3–5 target journals (check scope, impact factor, open access options)
- [ ] Confirm authorship order and contributions before writing
- [ ] Assess feasibility: do you have the data, time, and expertise?

**Output:** One-page project brief (question, novelty, target journal, authors, timeline).

### Phase 1 — Literature Review (1–2 weeks)

**Goal:** Map the field and find your gap.

- [ ] Run systematic search (PubMed, Embase, Cochrane, gray literature)
- [ ] Screen titles/abstracts → full text
- [ ] Build reference library in Zotero/Mendeley
- [ ] Identify the gap your study fills
- [ ] Note key papers you will cite (aim for 30–60 references for original research)

**Output:** Gap statement + reference library.

### Phase 2 — Data & Methods (1–4 weeks)

**Goal:** Lock down the data and analysis before writing.

- [ ] Clean and finalize the dataset
- [ ] Pre-specify the analysis plan (ideally before seeing results)
- [ ] Run the primary analysis
- [ ] Run sensitivity/supplementary analyses
- [ ] Create draft tables and figures (order: Table 1 = baseline, Table 2 = primary, etc.)
- [ ] Select the reporting guideline (CONSORT, STROBE, PRISMA, etc.)

**Output:** Finalized data, analysis, tables, and figures.

### Phase 3 — Outline (2–3 days)

**Goal:** Know what goes where before writing prose.

- [ ] Create section outlines (Introduction, Methods, Results, Discussion)
- [ ] Mark key data points and citations in the outline
- [ ] Verify logical flow (Introduction funnel: broad → gap → objective)
- [ ] Draft the abstract skeleton (will fill after Results are final)

**Output:** Structured outline with citations and data points marked.

### Phase 4 — First Draft (1–2 weeks)

**Goal:** Convert outline to full paragraphs. This is Stage 2 of the two-stage process.

- [ ] Write Methods first (most mechanical, establishes what you did)
- [ ] Write Results (let the data speak, reference tables/figures)
- [ ] Write Introduction (CARS model: territory → niche → occupy)
- [ ] Write Discussion (summary → comparison → mechanisms → limitations → future)
- [ ] Write Abstract last (distill from finished sections)
- [ ] Write title last (must reflect final findings, not initial hypothesis)

**Rule:** Do not edit while drafting. Get words on the page. Revision is Phase 6.

**Output:** Complete first draft in flowing prose.

### Phase 5 — Internal Review (1–2 weeks)

**Goal:** Catch problems before submission.

- [ ] Send to all co-authors with a deadline
- [ ] Ask mentor/supervisor for structural feedback
- [ ] Verify every statistic against source data
- [ ] Check all citations against original papers (not just abstracts)
- [ ] Identify sections that feel weak or unclear

**Output:** Compiled feedback list with action items.

### Phase 6 — Revision (3–5 days)

**Goal:** Address all feedback and polish.

- [ ] Resolve each comment from internal review
- [ ] Run Grammarly/Hemingway for readability
- [ ] Check paragraph transitions
- [ ] Verify terminology consistency (e.g., "patients" not "subjects" throughout)
- [ ] Ensure no bullet points in narrative sections
- [ ] Trim to word limit if over

**Output:** Revised draft ready for audit.

### Phase 7 — Pre-Delivery Audit (0.5 day)

**Goal:** Zero-tolerance quality gate.

- [ ] Run `resources/pre-delivery-audit.md` (33 items)
- [ ] Run `resources/ethics-and-integrity.md` checklist (Section 9)
- [ ] Verify all references resolve (DOI/PMID check)
- [ ] Confirm figures meet journal specs (DPI, format, color space)

**Output:** Audit report appended to document.

### Phase 8 — Submission (1 day)

**Goal:** Send it out.

- [ ] Format manuscript per journal guidelines (font, spacing, margins, line numbers)
- [ ] Write cover letter (address editor, state novelty, confirm no prior publication)
- [ ] Prepare title page (authors, affiliations, corresponding author, word count)
- [ ] Upload to submission system (Editorial Manager, ScholarOne, etc.)
- [ ] Verify all files uploaded correctly
- [ ] Confirm all co-authors approved the final version

**Output:** Submitted manuscript + submission confirmation.

## Stalled Project Diagnosis

If a manuscript is stuck, identify the phase and the block:

| Symptom | Likely Phase | Fix |
|---------|-------------|-----|
| "I can't start" | Phase 0–1 | Write a one-page brief; narrow scope |
| "I have data but can't write" | Phase 3 | Write the outline first, not the prose |
| "The draft is garbage" | Phase 4 | It's a first draft — keep going, fix in Phase 6 |
| "Co-authors won't respond" | Phase 5 | Set a firm deadline; send reminder after 7 days |
| "I keep rewriting the intro" | Phase 6 | Lock it. Move to Methods. Set a timer. |
| "Reviewer comments are brutal" | Phase 9 | Address point by point; don't argue, provide data |

## Time Estimates by Study Type

| Study Type | Phase 1 (Lit) | Phase 2 (Data) | Phase 4 (Draft) | Total to Submission |
|------------|---------------|----------------|-----------------|---------------------|
| Case report | 3–5 days | 1–2 days | 3–5 days | 2–3 weeks |
| Observational study | 1–2 weeks | 2–3 weeks | 1–2 weeks | 6–10 weeks |
| Clinical trial | 1–2 weeks | 4–8 weeks | 2–3 weeks | 10–16 weeks |
| Systematic review | 3–6 weeks | 2–4 weeks | 2–3 weeks | 10–16 weeks |
| Narrative review | 2–4 weeks | 1 week | 1–2 weeks | 5–8 weeks |
